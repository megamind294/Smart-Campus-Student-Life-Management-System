# Smart Campus demo specification
The approved project proposal is the uploaded Smart Campus PDF. Build a responsive React TypeScript SPA with six modules: overview, courses, assignments, calendar, grades/attendance, projects. Use JSON dummy records and the six confirmed team members. Clearly label sample academic data. The app uses browser localStorage only, with safe recovery from invalid storage and a user-confirmed reset. No backend, authentication, real university connection, or multi-user synchronization.
Tasks support create/edit/delete, due dates, priority, course and assignee, and three Kanban statuses. Drag/drop has an accessible select alternative. Calendar supports week navigation and event creation/edit/deletion; assignment deadlines derive from tasks. Grade averages are arithmetic means, attendance is attended sessions divided by recorded sessions. Group projects filter tasks by project and show owners. Course details show materials and assignments. Search filters the current module. Mobile navigation is accessible. The demo should run without API credentials.
